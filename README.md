# RSQ (Range Sum Query)

## Features
- O(1) insert back
- O(1) pop back
- O(1) range sum
- automatic memory growth
- automatic memory shrinking
- optional automatic free

## Include and compile
```c
#include "rsq.h"
```
```bash
gcc src/rsq.c examples/rsq_examples.c -I include -o example
```

See `examples/rsq_examples` for usage.
